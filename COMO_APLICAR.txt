CORREÇÃO: VOLTAR AO INÍCIO

1. Extraia o ZIP.
2. No GitHub, abra Ensaios-Filosoficos > templates.
3. Use Add file > Upload files e envie home.html deste pacote.
4. Confirme em Commit changes e aguarde a publicação na aba Actions.
5. Recarregue o site e teste o link no rodapé.

O alvo #inicio agora está no corpo do documento, em vez do cabeçalho sticky.
O GitHub Actions regenera a página automaticamente. Não é necessário rodar
comandos no computador. Os textos, o editor e o CSS não são substituídos.

Este template foi obtido da versão atual do GitHub em 6/9/2026. Se fizer
outras mudanças nele antes de aplicar, basta mover id="inicio" da tag
<header class="site-header"> para a tag <body>, preservando suas mudanças.

Conferência estrutural concluída: um único alvo inicio no body e três links
apontando para ele. O comportamento em navegador ainda precisa ser conferido.
