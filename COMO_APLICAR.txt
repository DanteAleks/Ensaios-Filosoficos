COMO APLICAR
1. Extraia o ZIP.
2. No repositório DanteAleks/Ensaios-Filosoficos, abra a pasta dist.
3. Clique em Add file > Upload files e envie o styles.css extraído.
4. Confirme a substituição com Commit changes na branch principal.
5. Aguarde a publicação concluir na aba Actions e recarregue o site.

Não é necessário executar node generate. A publicação já está automatizada.
