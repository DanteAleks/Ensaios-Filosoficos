Este pacote corrige as avaliações e acrescenta mensagens privadas para o autor.

1. Copie os arquivos mantendo as pastas para dentro do repositório Ensaios-Filosoficos.
2. Faça commit/push na branch main. O GitHub Pages executará scripts/generate.mjs.
3. No Cloudflare, execute reactions-service/schema.sql no D1, publique reactions-service/worker.mjs, vincule o D1 como DB e crie os segredos REACTION_SALT e MESSAGES_ADMIN_KEY.
4. Leia ATIVAR_AVALIACOES_E_MENSAGENS.md antes de configurar o Worker.

Não há senhas neste pacote. Os exemplos de chaves no manual são públicos e servem apenas para mostrar o formato; crie valores novos para uso real.
