# Coleções, novidades e manuscrito Peregrini — v11

Atualização preparada com os arquivos atuais consultados no GitHub e o acervo atual de duas obras. Nenhum texto autoral foi substituído.

## Instalar
Extraia o ZIP e copie as pastas para a raiz de sua cópia do repositório, MESCLANDO com as existentes e substituindo somente os arquivos correspondentes. Não apague as pastas antigas: este é um pacote de atualização. Ele não contém content/obras.json.

No Windows, copie as pastas extraídas para a pasta do repositório e confirme a substituição dos arquivos correspondentes. Faça commit e Push origin no GitHub Desktop. Espere build e deploy concluírem. Abra:
https://dantealeks.github.io/Ensaios-Filosoficos/admin/index.html?v=11
O topo indica v11. Não é necessário alterar Cloudflare.

## Coleções
Cada tema é um pequeno bloco com o número de obras e a publicação mais recente entre as obras datadas. Versões didáticas e sintéticas não duplicam a contagem. Os textos aparecem ao abrir o bloco. Ao abrir outro, o anterior se fecha. Links vindos da leitura abrem diretamente o tema correspondente. Os blocos funcionam sem JavaScript; a exclusividade de um aberto por vez usa JavaScript.

## Publicações recentes e datas
A nova seção lista até seis obras por data de primeira publicação, da mais recente para a mais antiga. Uma revisão não altera automaticamente a data original. Obras sem data continuam no acervo e nas coleções, mas não entram nas novidades até receberem uma data.

No editor da obra, use Data da primeira publicação ou Usar a data de hoje. Defina datas históricas corretamente. A obra de David Hume ainda estava sem data no catálogo consultado. Após preencher a data, clique em Publicar alterações.

Para associar a uma coleção já existente, use as caixas de seleção logo abaixo do campo Coleções. Para criar um tema, escreva seu nome nesse campo; separe múltiplos temas com ponto e vírgula. Os botões Antes/Depois na leitura continuam definindo a ordem autoral.

## Aparência
Coleções em forma de pequenos portais, bordas duplas, detalhes florais, aberturas de capítulo com iniciais ampliadas e cabeçalhos de leitura em arco. Tema claro/escuro, tamanho de fonte e leitura responsiva são preservados.
